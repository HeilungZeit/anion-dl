# anion-dl — справочник

Десктопное приложение на Tauri v2: каталог аниме из бэка `anion-go` + скачивание
серий через плеер Kodik в mp4 для офлайн-просмотра. Личный инструмент, не
публичный продукт. Авторизации нет.

Пошаговый план и история решений — [PLAN.md](PLAN.md). Здесь то, что нужно
знать, чтобы менять код и не наступить на уже пройденные грабли.

---

## Стек и конвенции

Angular 22 (zoneless, **без SSR**) + Taiga UI 5.9 + Tauri v2. Пакетный менеджер
— bun.

Конвенции унаследованы от [../anion/CLAUDE.md](../anion/CLAUDE.md) и действуют
здесь в полном объёме:

- `ChangeDetectionStrategy.OnPush` на каждом компоненте, состояние — только
  сигналы.
- Входы и выходы сигнальные: `input()`, `input.required()`, `output()`.
- DI только через `inject()` в поле класса.
- В шаблонах только встроенный control flow: `@if`, `@for` (с `track`),
  `@switch`, `@defer`.
- SCSS отдельным `styleUrl` рядом с компонентом.
- `strict`, `noUnusedLocals`, `noUnusedParameters`, `strictTemplates`. `any` не
  добавлять.
- Все страницы ленивые через `loadComponent`, у каждого роута есть `title`.

Отличия от основного проекта:

- **SSR нет** — плясок с `isPlatformBrowser` и `TransferState` не требуется.
- **`AxiosService` не переносим.** Весь ввод-вывод идёт через `fetch` из
  `@tauri-apps/plugin-http` (запрос уходит через Rust и не подчиняется CORS).
- **`@taiga-ui/legacy` не подключён** и подключать не нужно.
- Taiga запинен на 5.9.0 **везде**: `^5.9.0` для layout/styles резолвится в
  5.17 и даёт рассинхрон с core.
- Angular 22 требует TypeScript ровно 6.0.x; тема Taiga — `.less`, поэтому
  пакет `less` в devDependencies обязателен.
- Persistent cache Angular отключён в `angular.json`: связка Angular 22.1.2,
  `lmdb` 3.5.6 и Node 24.16 падает с double-free внутри нативного addon ещё до
  диагностики сборки. Без LMDB проект собирается примерно за три секунды.

## Как это устроено

```
┌─ Angular UI ────────────────────────────────────┐
│ Feed · Catalog+Search · Anime · Downloads       │
└───────────┬─────────────────────┬───────────────┘
            │ tauri-plugin-http   │ invoke() + events
            ▼                     ▼
      anion-go /api        ┌─ Rust ───────────────┐
                           │ resolver.rs          │
                           │ download.rs          │
                           └──────────────────────┘
```

Очередь живёт в TS (`DownloadService`), процессы ffmpeg — в Rust.

### Данные

Бэк `anion-go` отдаёт готовые ссылки на плееры, **скрейпить anion.online не
нужно**. Публичные эндпойнты (auth только на `/user` и `/bookmarks`):

| Эндпойнт | Отдаёт |
|---|---|
| `GET /api/anime/feed` | `seasonAnime`, `schedule`, `updates` |
| `GET /api/anime?<фильтры>` | список `Anime[]` |
| `POST /api/anime/search` | список `Anime[]`, строка в поле `search` |
| `GET /api/anime/:id` | детали + `videos[]` |
| `GET /api/anime/genres` | жанры |

В `videos[]` у каждой серии есть `iframeUrl` — прямой URL плеера, плюс
`data.player`, `data.dubbing` и `skips` с таймингами опенинга.

База API — `https://anion.online/api` (см. `src/app/api/api.config.ts`).
Разрешённые хосты перечислены в `src-tauri/capabilities/default.json`; запрос на
неразрешённый origin плагин отклонит.

### Резолвер

Манифест не лежит в разметке: плеер получает его отдельным запросом, ссылка
приходит обфусцированной (base64 + посимвольный сдвиг) и раскрывается в JS.
Реверсить бессмысленно — обфускация меняется с релизами. Вместо этого страница
выполняется в скрытом вебвью, а мы подслушиваем её сетевые запросы.

### Скачивание

Ремукс без перекодирования (`-c copy`): поток не зашифрован и уже в H.264 + AAC.
DRM у Kodik нет вовсе — ни Widevine, ни ClearKey, ни EME.

## Грабли, на которые уже наступили

Каждый пункт стоил отладки. Прежде чем «упростить» — прочитать.

### Резолвер

**`window.title()` не отражает `document.title`.** Возвращает заголовок окна ОС,
который Tauri с документом не связывает. Нужен push-колбэк
`on_document_title_changed`.

**Плеер живёт во вложенном iframe.** В главном документе нет ни `<video>`, ни
запросов за видео. Обязателен `initialization_script_for_all_frames`.

**Из фрейма нельзя писать заголовок верхнего документа.** Фреймы шлют
`postMessage` наверх, заголовок пишет только верхний фрейм.

**Состояния фреймов копить, а не перезаписывать.** Иначе в диагностику попадает
случайный последний фрейм (обычно статистика `ls.kodikres.com`), а плеерный не
виден.

**Кнопка запуска — `<a class="play_button">`.** Без клика по ней плеер не
запрашивает манифест вообще. Ни один «типовой» селектор плееров по ней не
попадает.

**Канал наружу — `document.title`, не IPC.** Remote-IPC потребовал бы внести
`kodikplayer.com` в capabilities, то есть выдать чужой странице доступ к
командам приложения ради одной строки.

**Фильтровать по домену CDN нельзя.** В CSP на anion.online значится
`video-lk-ok-ii.store`, но при прямой загрузке Kodik манифест приходит с
`cloud.solodcdn.com`. Контент опознаётся по форме URL:
`…/<качество>.mp4:hls:manifest.m3u8`.

**Качество зашито в имя манифеста.** Плеер стартует с 360p, поэтому пойманный
манифест всегда низкого качества; нужное добирается подменой числа. Существование
проверять запросом обязательно: 1080p и 240p отдают 404 при рабочих 720/480.

### Скачивание

**`out_time_ms` содержит МИКРОсекунды**, вопреки имени. Делить на 1e6.

**`-headers` — приватная опция http-протокола.** На локальном файле ffmpeg
падает с «Option not found», поэтому тестировать только через http.

**`exit=0` не означает целый файл.** При обрыве сегмента ffmpeg молча
продолжает и оставляет дыру. Обязательны `-reconnect*`.

**Детектор целостности трижды был слишком строгим.** Итоговое правило: **ошибка
— только заметный недобор длительности** (допуск 1%, но не меньше 5 с). Не
считать браком:

- «Connection to tcp:// … failed» — с ретраями штатно восстанавливается;
- жалобы декодера (`non-existing PPS`, `no frame!`) — HLS часто стартует не с
  ключевого кадра, пара жалоб норма; сверх порога это предупреждение, не отказ;
- недобор в секунду-другую — последний блок `-progress` печатается до
  финального сброса буферов.

Дыру в середине не ловит ни одна проверка: при `-c copy` таймстемпы сохраняются
и длительность остаётся полной. Осознанный размен — гонять человека
перекачивать 24 минуты из-за подозрения дороже, чем пропустить полсекунды.

**`-movflags +faststart` обязателен.** По умолчанию `moov` пишется после `mdat`,
и плееры (в том числе телеграмный) не начинают воспроизведение, пока не
скачают файл целиком.

**Явные `-map 0:v:0 -map 0:a:0`** — иначе при нескольких аудиодорожках ffmpeg
может взять не ту озвучку. **`-bsf:a aac_adtstoasc`** обязателен при TS → MP4.

### Сайдкар и сборка

**`tauri-build` проверяет `externalBin` на этапе компиляции** — без файла падает
даже `cargo build`.

**Имя файла обязано нести target triple**: на диске
`binaries/ffmpeg-aarch64-apple-darwin`, в `tauri.conf.json` — путь **без**
суффикса. Причина №1 ошибки «sidecar not found». Второй частый случай —
отсутствующее `shell:allow-execute` со scope.

**При `--disable-everything` нужны декодеры и парсеры `h264`/`aac`.** Сам
ремукс по-прежнему идёт через `-c copy`, но без зарегистрированных декодеров
`avformat_find_stream_info` не извлекает из MPEG-TS размеры видео и параметры
аудио. MP4-мультиплексор падает с `dimensions not set`. Это проверено отдельно:
одних парсеров недостаточно.

**`opener:default` не покрывает раскрытие пути** — для «Показать в Finder»
нужен `opener:allow-reveal-item-in-dir`.

### UI

**Визуальный язык синхронизирован с основным фронтом `anion`.** Цвета,
поверхности, радиусы, отступы, состояния фокуса и акцентные градиенты заведены
как `--anion-*` в `src/styles.scss`. Шапка повторяет композицию веб-фронта:
стеклянный фон, wordmark, компактные активные пункты и отдельный вход в поиск.
Карточка `AnimeCardComponent` имеет два варианта: постерный для главной и
горизонтальный `wide` для каталога. Бизнес-специфичные экраны скачивания
используют те же токены, а не стандартный вид Taiga.

Каталог повторяет раскладку основного фронта: раскрываемая навигация по жанрам,
сетка горизонтальных карточек и липкая панель фильтров справа. Название, жанры,
тип, статус, диапазон лет и сортировка реально передаются в `AnimeQuery`;
массивы по-прежнему сериализуются одной строкой через запятую. Селекты в
фильтрах и на странице аниме собраны через `TuiSelect` внутри `tui-textfield` —
нативные `<select>` сюда не возвращать.

Каталог и поиск используют серверную пагинацию по 20 элементов. Бэк не отдаёт
`total`, поэтому запрос берёт 21 элемент: первые 20 показываются, 21-й служит
точным признаком наличия следующей страницы. При поиске и изменении фильтров
страница сбрасывается на первую. Начальная сортировка — `top`
(`Релевантности`), как на основном фронте.

**Не передавать обычный stringify-колбэк в `itemContent` у
`tui-data-list-wrapper`.** `itemContent` — PolymorpheusContent: функция получает
контекст `{$implicit: item}`, а не сам item. Для чисел это дало
`[object Object]p`, для объектных опций — пустые строки. Достаточно задать
`[stringify]` на родительском `tui-textfield`: wrapper унаследует его через
items handlers. У одиночного поискового поля cleaner отключён, а высота
`.filter-control` явно зафиксирована на `--tui-height-m`, иначе служебный
контент Taiga мог перенестись на вторую строку и растянуть поле.

Иконка шапки не дублируется в `src/assets`: Angular копирует master-файл
`src-tauri/icons/app-icon.png` в `assets/app-icon.png` через `angular.json`.

**Окно самостоятельно не открывать для проверки UI** — это унаследованное
правило `../anion/CLAUDE.md`. Production-сборка и упаковка `.app` проверяют
шаблоны, типы и доступность ассетов, визуальную приёмку проводит пользователь.

**Цепочка высот до скролл-контейнера должна быть определённой.** Между `body` и
`tui-root` стоит `app-root` с `display: block` без высоты — именно там она
рвалась. `body` — флекс-контейнер, `app-root` — `display: flex; flex: 1`.

**`overflow: hidden` на скроллере глушит колесо, но не `scrollTop`.** Кастомный
скроллбар Taiga (`tui-scroll-controls`) двигает контейнер программно, поэтому
симптом выглядит как «ползунок тащится, колесо мертво».

**`data.player` — подпись, а не идентификатор.** Реальные значения «Плеер
Kodik», «Плеер Alloha». Сравнение только по вхождению подстроки.

**Массивы в query бэк режет по запятой** (`strings.Split(val, ",")`).
Повторяющиеся ключи он не увидит — `c.Query` вернёт только первый.

**На `/api` висит рейт-лимитер.** Без клиентского кэша обычная навигация
упирается в 429.

## Решения, которые выглядят странно, но осознанны

**Параллелизм загрузок = 1.** CDN показывал таймауты и на одном потоке;
несколько одновременных ffmpeg только повысят шанс потерять сегмент, а выигрыша
нет — упирается всё в сеть.

**Прогресс не сохраняется между запусками.** ffmpeg не умеет дописывать
частичный mp4, прерванная загрузка честно начинается заново.

**Резолв — внутри обработчика очереди, а не при постановке.** Подписи в URL
сегментов протухают; манифест, добытый впрок на весь сезон, к своей очереди
будет мёртв.

**Отмена живёт в Rust.** Из JS ручку дочернего процесса не достать, брошенный
ffmpeg продолжил бы качать в фоне.

**Диагностика резолвера оставлена в коде.** При таймауте ошибка содержит
состояние всех фреймов. Без неё отладка была гаданием — это проверено.


```bash

```

Прогнать резолвер из терминала, без кликов по окну:

```bash
cd src-tauri && cargo run --example resolve_probe -- "<URL плеера>" 720
```

```bash
cd src-tauri && cargo test --lib
```

Собрать запиненный LGPL ffmpeg из официальных исходников для текущей платформы
(имя с триплетом делает сам скрипт):

```bash
./scripts/fetch-ffmpeg.sh
```

Первым аргументом можно передать target triple. Для сборки без скачивания путь
к архиву `ffmpeg-8.1.2.tar.xz` передаётся вторым аргументом:

```bash
./scripts/fetch-ffmpeg.sh x86_64-unknown-linux-gnu /path/to/ffmpeg-8.1.2.tar.xz
```

Публикация релиза запускается только версионным тегом, совпадающим с версией в
`src-tauri/tauri.conf.json`:

```bash
git tag app-v0.1.0
git push origin app-v0.1.0
```

Workflow `.github/workflows/release.yml` создаёт публичный GitHub Release и
загружает DMG для macOS ARM/Intel, NSIS EXE для Windows x64, AppImage и DEB для
Linux x64. Подпись и нотарификация намеренно не настроены.

## Состояние

Э0–Э7, упаковка macOS и синхронизация UI с фронтом `anion` закрыты, выбор
качества и защита от рекламного манифеста сделаны.
Приложение работает: каталог, поиск, детали, очередь, скачивание в mp4.

ffmpeg 8.1.2 собирается скриптом из официального архива с проверкой SHA-256.
Сборка LGPL без энкодеров; TLS идёт через Secure Transport на macOS, SChannel
на Windows и OpenSSL на Linux. На macOS sidecar весит 2,4–2,6 МБ и зависит
только от системных библиотек. Проверены обе macOS-архитектуры, локальный HLS и
25 секунд живой серии Kodik: H.264 High 1280×720 + AAC-LC, `moov` в начале.

Собственная иконка хранится в `src-tauri/icons/app-icon.png`; остальные размеры
генерируются через `bun run tauri icon src-tauri/icons/app-icon.png`.

DMG собирается для arm64, приложение и ffmpeg подписываются ad-hoc identity
`"-"` с hardened runtime. `codesign --verify --deep --strict` проходит. Это
обеспечивает целостность пакета, но **не заменяет Developer ID и нотарификацию**:
на другой машине macOS всё равно потребует разрешить запуск в Privacy & Security.

## Дорожная карта

**Э6 — минимальная LGPL-сборка ffmpeg. ✅ Сделано.**

Автономный sidecar собран из FFmpeg 8.1.2 с `--disable-everything`, без
`--enable-gpl`, x264/x265 и сторонних dylib.

- Включены демуксеры `hls`/`mpegts`, муксер `mp4`, протоколы
  `file,http,https,tcp,tls,pipe`, BSF `aac_adtstoasc`, парсеры и декодеры
  `aac,h264`. Декодеры нужны только для анализа параметров потока; энкодеров нет.
- [scripts/fetch-ffmpeg.sh](scripts/fetch-ffmpeg.sh) фиксирует версию и SHA-256,
  собирает бинарь и перед установкой отклоняет GPL или несистемные dylib.
- Итоговый размер 2.4 МБ. `otool -L` на sidecar внутри собранного `.app`
  показывает только `/usr/lib` и Frameworks из `/System/Library`.
- Проверены HTTPS через Secure Transport, полный локальный HLS-ремукс и
  25-секундный фрагмент живой серии Kodik из актуального манифеста.

**Упаковка macOS. ✅ Сделано.** Собственная squircle-иконка с прозрачными углами
проверена в размерах 32/128/512 px. `anion-dl_0.1.0_aarch64.dmg` проходит
`hdiutil verify`; внутри есть ссылка на `/Applications`, корректно подписанные
app/sidecar и тот же автономный LGPL ffmpeg без Homebrew-зависимостей.

**Э7 — GitHub Releases. ✅ Настроено.** Тег `app-v<версия>` запускает матрицу
GitHub Actions для macOS ARM/Intel, Windows x64 и Linux x64. Workflow собирает
sidecar на целевой ОС, создаёт недрафтовый Release и загружает DMG, NSIS EXE,
AppImage и DEB со стабильными именами. Версия тега обязана совпадать с
`tauri.conf.json`.

Подпись Windows, Developer ID и нотарификация Apple сознательно не делаются:
пользователь получит системное предупреждение при первом запуске.

Alloha как второй источник — отдельная история и пока не нужна: у него
Guard-верификация, капча и каскад фолбэк-манифестов, которых у Kodik нет.
