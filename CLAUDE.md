# anion-dl

Tauri v2 + Angular 22 (zoneless, без SSR) + Taiga UI 5.9. Скачивает серии через
плеер Kodik в mp4 для офлайн-просмотра. UI-тексты — на русском.

**Перед работой прочитать [AGENT.md](AGENT.md).** Там архитектура, конвенции,
команды, дорожная карта и — главное — список уже пройденных граблей: неочевидные
особенности Tauri, ffmpeg, Kodik и вёрстки, каждая из которых стоила отладки.
Правки без этого контекста с большой вероятностью воспроизведут уже решённую
проблему.

История решений по этапам — [PLAN.md](PLAN.md).

Конвенции Angular наследуются от [../anion/CLAUDE.md](../anion/CLAUDE.md) и
действуют здесь полностью; отличия перечислены в AGENT.md.
